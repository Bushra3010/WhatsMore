# Legacy HTML version

The original plain HTML/JS version of WHATSMORE (before the Next.js rewrite in `web/`). It is no longer
published, except the old Command Center page (`admin.html` + `css/admin.css` + `js/admin.js`), which the
GitHub Pages workflow serves at `/WhatsMore/admin.html` until the new admin panel (`web/app/admin`) is hosted
on a server (it checks admin rights on the server, so it can't run on GitHub Pages).
